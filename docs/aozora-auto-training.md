# 青空文庫の自動学習

`scripts/auto-train-aozora.py` は公開目録から作品を自動選別し、ローカルで文字2/3-gramを学習します。ChatGPT自体の再学習や大規模言語モデルの訓練ではありません。入力履歴を外部へ送信しません。

```powershell
python scripts/auto-train-aozora.py --download --refresh-index
```

最初に目録を取得し、作品と全著者の著作権フラグが「なし」、役割が「著者」、公式サイトのテキストZIPがある単著の作品を選びます。共著・翻訳・編集者のある作品は今回の対象外です。[青空文庫の取り扱い規準](https://www.aozora.gr.jp/guide/kijyunn.html)に従い、書誌情報のCC BY 4.0表示、著者、入力者、校正者、元の冒頭・底本情報を学習レポートに保持します。注記ガイドを識別できない形式や空の本文はスキップし、理由を記録します。旧仮名・旧漢字を現代語に直す処理はありません。

取得は直列で、ネットワーク取得ごとに1秒待機します。通信失敗が10回連続すると停止します。SQLiteに作品単位で進捗を確定するため、同じコマンドで再開できます。URLと目録情報をキャッシュキーに含め、更新・権利変更・削除が確認された作品の旧学習データを除去します。目録の最新化には `--refresh-index` を指定してください。実行中の再起動はロックにより拒否されます。

`--max-books 100` は今回処理する新規作品を100件に制限します。省略時は対象目録全体です。`--download` なしなら検証済みのキャッシュだけを処理します。全対象の取得には長時間かかります。途中終了した作品は再開時に再処理されます。

本文はSQLiteから順に読み、重複文は評価側を優先して除去します。同じ著者を同じ区分に割り当て、訓練・検証・テストを分離します。出現3回以上の上位20万特徴を既存Rustコアが読める `NXAI0001` 形式で出力します。100件処理ごとと正常終了時に学習成果物を保存します。集計用の特徴カウンターはRAMを使用します。大規模目録での最大RAM量・時間はまだ未測定です。

出力は `.cache/aozora-auto/releases/<モデルSHA-256>/` のモデルと出典レポートです。`.cache/aozora-auto/releases/latest.json` を原子的に切り替えます。既存モデルも残るため比較・復元できます。進捗は `progress.sqlite3`、終了時の状態は `status.json`、取得・スキップ・学習結果は標準出力です。最終成果物の `pending_books` が0かどうか、エラーがないかを確認してください。本文の単純な隣接文字交換との比較は実際の変換精度の測定ではありません。

自動取得・学習と、IMEへの配布・適用は別の操作です。今回は候補品質の回帰検証前に稼働中IMEへ自動適用しません。既存の英語コーパスも置き換えません。Windowsの前回の更新確認はキャンセルされたため、現在登録されているIMEにこの成果物はまだ入っていません。全文庫の学習完了・定期実行・変換精度向上を実証した状態ではありません。

動作検証:

```powershell
python scripts/test-auto-train-aozora.py
```

公式URL制限、全著者の権利確認、著者ごとの区分固定、改訂の原子的な置換、形式不明時の旧データ保持、区分をまたぐ重複文の訓練除外、モデルSHA-256・バイナリ長の整合性を確認します。CIでは外部へのアクセスを行わず、このテストを実行します。

## 2026-10-11 実行確認

対象16,243作品の自動取得をバックグラウンドで開始しました。最初のチェックポイントは145作品、訓練18,959文章片、検証32,151文章片、テスト775文章片、66,017特徴、1,056,280バイトでした。モデルSHA-256は `7be6c31d5e3a641d233ea834915ff08544bbfd05eeba3b5f1eb4cf9321af6312`。隣接文字交換の限定評価は773対、勝ち663・同点20・負け90です。目録順に取得中の部分的な成果であり、全件学習済みではありません。著者単位の分離によってこの時点の検証用文章片が訓練より多くなっています。

Pythonテスト11件、Rustテスト60件、fmt、clippy、releaseビルドが成功しました。GitHub Actionsには追加テストを登録しましたが、GitHub上の実行はまだです。取得全体の時間・メモリ・IME精度ベンチマークは未完了です。

今回の実行ログは `.cache/aozora-auto/run.log`、エラーは `run-error.log`、起動情報は `running.json` にあります。これはWindowsの常駐サービスや定期実行の登録ではなく、起動済みPythonプロセスです。PCの再起動で停止した場合は上記コマンドで再開します。

```powershell
Get-Content .cache/aozora-auto/run.log -Tail 5
Get-Content .cache/aozora-auto/run-error.log -Tail 5
```
